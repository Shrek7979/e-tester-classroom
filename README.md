# e-Tester

번호 타일을 무작위로 섞어 완전불일치 확률을 구하고 자연상수 e를 발견하는 교사 연수 앱입니다. 기존 통계 마술쇼와 통계 법정 앱을 대체했습니다.

- [GitHub Pages에서 앱 실행](https://shrek7979.github.io/e-tester-classroom/)
- [기존 앱 주소](https://stats-magic-show.web.app/)

- [참여 안내](COMMUNITY.md)

## 실행

`python -m http.server 3015` 실행 후 `http://localhost:3015/`를 엽니다. 개인 실험은 서버 연결 없이도 작동합니다. `/lab.html`은 새 앱으로, `/host.html`은 진행자 방 만들기로 연결합니다.

## 30분 연수

1. **예측 5분**: 진행자가 방을 만들고 참가 코드를 공유합니다. 참가자가 별명으로 입장해 완전불일치 확률을 예상합니다. 기본 타일 수는 13개입니다.
2. **공동 실험 15분**: 진행자가 ‘실험 시작’을 누릅니다. 각자 1회, 10회, 1,000회씩 섞습니다. ‘우리의 데이터’에서 같은 라운드와 n의 결과를 합칩니다.
3. **발견과 설명 10분**: 진행자가 ‘e와 해설 공개’를 누릅니다. 전체 시행 / 성공 횟수를 e와 비교하고 n=4의 24가지 배열과 포함배제를 탐구합니다.

타일 수 변경과 새 라운드는 기존 결과와 섞이지 않게 별도의 라운드를 만듭니다. 바꾸기 전 CSV로 집계를 내려받을 수 있습니다. n을 늘리는 것과 시행을 늘리는 것은 다릅니다.

## 연결

- 온라인 방: 기존 Firebase Realtime Database의 `show/eTester/rooms/{code}`를 사용합니다. 방 설정과 라운드별 참가자 집계를 분리하고, 참가자별 절대 누적값을 저장하여 재전송이 중복 집계되지 않게 합니다. 2초마다 집계를 갱신합니다.
- 실시간 의견: 방에 들어오면 화면 위 ‘실시간 의견’ 패널에서 반응 버튼(이해됐어요·질문 있어요·예상과 달라요)과 한 줄 의견을 보낼 수 있습니다. 메시지는 `talk/{id}`에, 진행자가 띄운 질문은 `config.prompt`에 저장되어 같은 2초 폴링으로 모든 참가자에게 전달됩니다. 진행자는 질문을 바꾸거나 의견을 비울 수 있습니다.
- 각 방은 별개의 참가 코드를 사용합니다. 참가 코드를 아는 사람이 자료에 접근할 수 있는 연수용 서비스입니다. 진행자에 별도 인증이 없으므로 공개 대규모 서비스용은 아닙니다.
- 연결 실패 시 탭에 결과를 보관하며 ‘결과 다시 전송’으로 재시도합니다. 서버 저장 확인 전에는 전송 대기로 표시합니다.
- 리허설: 방 만들기와 참가 시 ‘같은 브라우저에서만 리허설하기’를 선택합니다. localStorage를 사용하며 다른 기기에는 연결되지 않습니다.
- 로컬 주소 localhost는 다른 기기에서 접속할 수 없습니다. 휴대폰 공동 참여에는 배포 주소를 사용합니다.

## 수학과 원고

제출용 `e-Tester with Arduino_Ver2.0(제출용).pptx`의 12–17쪽을 참고했습니다. 아두이노와 회로, 코딩 교육 내용은 제외했습니다. 16쪽 표기의 오류를 수정해 `D4 = 24 - 4*6 + 6*2 - 4*1 + 1 = 9`로 계산합니다.

- 매 시행은 Fisher–Yates 셔플로 실제 순열을 생성합니다. 고정점이 0개면 성공입니다.
- 정확한 확률 `p_n = Σ(k=0..n) (-1)^k / k!`은 n이 커질 때 `1/e`에 수렴합니다.
- `전체 시행 / 성공`은 유한 n에서 엄밀히 `1/p_n`의 추정입니다. 작은 n에서 e와 다른 값을 갖는다는 점을 표시합니다.
- 성공 0회이면 역수 추정값을 표시하지 않습니다. 신뢰구간은 성공 비율에 대한 Wilson 95% 근사 구간입니다.

## 파일과 배포

`index.html`, `style.css`, `app.js`, `math.js`가 새 앱입니다. `firebase-config.js`는 기존 연결 설정입니다. `build.ps1`은 배포할 웹 파일만 `dist`에 복사합니다. 원고, 설명 문서, 검증 자료는 배포하지 않습니다.

```powershell
node tests/math.test.cjs
./build.ps1
firebase deploy --only hosting --non-interactive
```

Firebase Hosting 프로젝트는 기존 `stats-magic-show`를 사용합니다. 배포 후 새 앱 주소는 `https://stats-magic-show.web.app/`입니다. 이 README의 주소만으로 배포 완료를 의미하지 않으며 실제 배포 결과를 확인해야 합니다.

## 폴더 구성

- 루트: e-Tester 앱(`index.html`, `app.js`, `math.js`, `style.css`)과 Firebase·GitHub Pages 설정, `tests/`.
- `차시별 시뮬레이터(통계교사연구회)/`: 7차시 통계 탐구(1~6차시 시뮬레이터와 7차시 e-Tester)의 모음. `index.html`이 시연 목차이고 `수학카드.html`이 시뮬레이터별 A5 수학 카드(12장)입니다. 3·5차시가 쓰는 그림은 `images/`, 1·4차시의 원본 Colab 노트북과 실행 결과 페이지는 `원본노트북/`에 있습니다. GitHub Pages에서 같은 경로로 열립니다.
- `발표자료/`: 연수 발표 덱(통합 16장, 소개 11장, e-Tester 5장)과 접속 QR. 이전 판과 구버전 앱(통계 법정) 설명서는 `이전버전/`에 둡니다. pptx·docx·pdf는 저장소에 올리지 않습니다.
- `dist/`: `build.ps1`이 만드는 Firebase 배포용 복사본으로, 저장소에 올리지 않습니다.

## 참고 사이트를 반영한 관찰 기능

[ShrekMath e-Tester](https://shrek7979.github.io/e_Tester/)의 자동 시행과 속도 조절, 번호별 제자리 빈도를 참고해 공동 실험 흐름에 맞게 구현했습니다. 소스와 외부 스크립트를 복사해 넣지 않고 기존 엔진으로 구현했습니다.

- 자동 시행은 0.15~1.50초 간격으로 한 번씩 섞습니다. 다른 탐구 탭에서도 계속되며 상단의 정지 버튼으로 멈춥니다. 서버 응답을 기다린 후 다음 시행을 예약해 중첩 실행을 막습니다. 온라인 자동 시행 집계는 약 1.5초마다 저장하며 정지할 때 마지막 집계를 전송합니다. 네트워크 저장 실패 시 자동 시행을 멈춥니다.
- 번호별 제자리 빈도는 새로 기록된 시행만 분모에 사용합니다. 구버전 기록에 번호별 계수가 없어도 0회로 오해하지 않게 별도 시행 수를 저장합니다.
- 해설 공개 후 누적 그래프는 유한 n의 정확한 확률 p_n과 극한값 1/e를 함께 표시합니다. 번호별 빈도의 기준은 1/n입니다.
- 검증 명령: `node tests/room.test.cjs`는 공동 집계, 오프라인 재시도, 라운드 분리, 번호별 집계와 자동 시행 중복/정지를 확인합니다.
