확률실험 시뮬레이터

상대도수큰수의 법칙오차한계

동전·주사위·뽑기를 반복하며 상대도수가 확률에 가까워지는 과정, 그리고 ‘얼마나 반복해야 충분한가’를 비용과 함께 따져 봅니다.

수학적 원리

시행 n번 중 사건 횟수 X ~ B(n, p)
상대도수 X/n의 평균 = p, 표준편차 = √(p(1−p)/n)
  • 큰수의 법칙: n이 커지면 상대도수는 p에 가까워집니다. 단, 한 경로의 오차가 매번 줄어드는 것이 아니라 흩어짐의 폭이 1/√n으로 줄어듭니다.
  • 오차한계(2σ): E = 2√(p(1−p)/n) → 필요한 시행 수 n = 4p(1−p)/E²
p = 0.05: E ≤ 0.01 → n ≥ 1,900회 · E ≤ 0.005 → n ≥ 7,600회
1,000번 뽑기: 평균 50, σ = √47.5 ≈ 6.9 → ‘30회 이하’는 −2.8σ, 약 0.2%

시뮬레이터에서 확인하기

  • 실험 1: 로그 스케일에서 경로 5개가 0.5로 모이는 모습, 10·100·1,000·10,000회 표
  • 실험 2: n = 60, 600, 6000 히스토그램 폭이 1/√10씩 줄고 표준편차 그래프가 이론선과 겹침
  • 실험 3: 오차한계·비용 그래프에서 0.01, 0.005를 넘는 첫 n, 2,000번 반복 실험의 ‘운 나쁨’ 비율

원주율 시뮬레이터

기하확률몬테카를로1/√N

정사각형 안에 점을 무작위로 뿌려 단위원에 들어간 비율로 π를 추정합니다. 점의 수 N, 난수 시드, 속도를 조절합니다.

수학적 원리

(x, y) ~ [−1, 1]² 균등분포 → P(x² + y² ≤ 1) = π/4
원 안의 점 S ~ B(N, π/4), 추정값 π̂ = 4S/N
  • E[π̂] = π (편향 없음), SD(π̂) = 4√(p(1−p)/N) ≈ 1.64/√N (p = π/4 ≈ 0.785)
  • 오차가 1/√N으로 줄어드므로 소수 한 자리를 더 얻으려면 점이 100배 필요합니다.
N = 10,000 → SD ≈ 0.016 · N = 100,000 → SD ≈ 0.005
95% 범위: π̂ ± 2·SD

시뮬레이터에서 확인하기

  • N을 1,000 → 10,000 → 100,000으로 키우며 추정값과 절대 오차의 변화 관찰
  • 같은 시드로 ‘새로 시작’하면 같은 결과가 재현됨 (난수의 재현성)
  • 절대 오차가 단조롭게 줄지 않는 순간을 찾아 ‘수렴’의 뜻 이야기하기

원주율 시뮬레이터 + 배치 반복 분석

반복 실험표본 표준편차N과 M

같은 N으로 추정을 M번 독립 반복해 추정값들이 얼마나 흩어지는지 재고, N 조건별로 비교합니다.

수학적 원리

M개의 추정값 π̂₁, …, π̂M → 표본 표준편차 s ≈ 1.64/√N
N이 4배 → s는 1/2, N이 16배 → s는 1/4
  • N(점의 수)은 추정 한 번의 정밀도를, M(반복 횟수)은 그 흩어짐을 얼마나 잘 관찰하는지를 결정합니다. M을 늘려도 π 추정 자체가 정밀해지지는 않습니다.
  • 추정값들의 평균은 π 근처에 머뭅니다(편향 없음). 흩어짐의 95% 범위는 약 π ± 2s입니다.

시뮬레이터에서 확인하기

  • N 조건 1,000 / 4,000 / 16,000, M = 50으로 배치 분석 실행 → 표준편차가 1/2씩 줄어드는지
  • 배치 시드를 바꿔 다시 실행했을 때 표준편차 자체도 조금씩 달라지는 것
  • M만 50 → 200으로 늘렸을 때 바뀌는 것과 바뀌지 않는 것 구분

발전기 용량 몬테카를로

확률변수의 합기댓값·분산의사결정

행사장 부스 30개의 총전력을 무작위로 만들어, 발전기 용량 B가 수요를 감당할 확률을 추정하고 ‘95% 정상 운영’ 용량을 정합니다.

수학적 원리

부스 1개 소비전력 C ∈ {1, 2, 3}, 확률 0.6 / 0.3 / 0.1
E(C) = 1.5, V(C) = 0.45
총전력 T = C₁ + … + C₃₀ → E(T) = 45, SD(T) = √13.5 ≈ 3.67
  • 정상 운영 확률 = P(T ≤ B). 시뮬레이션에서는 M번 중 T ≤ B인 비율로 추정합니다.
  • 정규근사로 어림하면 95% 보장 용량 B ≈ 45 + 1.645 × 3.67 ≈ 51.0 → 약 52. 정확한 값은 이산분포의 누적비율(시뮬레이션 표)로 확인합니다.

시뮬레이터에서 확인하기

  • 총전력 히스토그램의 중심(45)과 폭, 종 모양으로 정리되는 과정
  • 용량별 정상 운영 확률 표에서 95%를 처음 넘는 B
  • 반복 M = 1,000 / 5,000 / 20,000 비교: 확률 곡선이 안정되는 정도

갈톤보드: 확률 실험기

이항분포기댓값게임 규칙 설계

층 수 k, 오른쪽으로 갈 확률 p, 공 개수를 바꾸며 공이 쌓이는 칸의 분포를 관찰하고, 목표 칸 미션과 보상 규칙 설계로 이어 갑니다.

수학적 원리

오른쪽 이동 횟수 X ~ B(k, p), 도착 칸 = X
E(X) = kp, V(X) = kp(1−p), 최빈값 ≈ ⌊(k+1)p⌋
P(X = x) = C(k, x) px(1−p)k−x
  • 목표 칸 m을 맞추려면 평균 kp ≈ m, 즉 p ≈ m/k로 조절합니다. 최빈값이 평균과 정확히 같지는 않습니다.
  • 보상 규칙: 기대 운영 비용 = Σ P(x) × 상품가 < 플레이 비용. 특별 상품 확률 5~10%, 일반 상품 30% 이상 조건을 함께 만족시킵니다.

시뮬레이터에서 확인하기

  • ‘새 미션 받기’ 후 힌트(평균 ≈ np)로 p를 조절해 목표 칸 맞추기
  • p = 0.5와 0.3에서 중심과 비대칭의 변화, 층 수를 늘릴 때 종 모양 접근
  • 공 120개와 1,000개에서 최빈 칸이 달라지는 경우 비교

추정 시뮬레이터

표준오차신뢰구간오차 한계

배터리 수명 모집단(μ = 500시간, σ = 20시간)에서 표본을 반복해 뽑아 표본평균의 분포, 신뢰구간의 뜻, 오차 한계와 조사 비용을 살핍니다.

수학적 원리

Xᵢ ~ N(μ, σ²) → 표본평균 X̄ ~ N(μ, σ²/n), SE = σ/√n
n = 25 → SE = 4 · n = 100 → SE = 2 (표본 4배, 폭 1/2)
  • 95% 신뢰구간 X̄ ± 1.96σ/√n (n = 25: ±7.84). 같은 절차를 반복하면 구간의 약 95%가 μ를 포함한다는 뜻입니다.
  • 오차 한계 E = 1.96σ/√n → 필요한 표본 n = (1.96σ/E)²
E ≤ 2 → n ≥ 385 (목록에서는 400) · 표본 1개 5만원 → 약 1,925만원

시뮬레이터에서 확인하기

  • 실험 1: n = 25와 100의 히스토그램 폭, 실제 표준오차와 σ/√n의 비율 ≈ 1
  • 실험 2: 100개 구간 중 빨간(놓친) 구간 수, 반복할수록 누적 포함 비율이 95%로
  • 실험 3: 비용은 n에 비례, 오차 한계는 1/√n → 정밀도 향상의 둔화

이항분포와 정규분포 비교 시뮬레이터

정규근사np, n(1−p)연속성 보정

갈톤보드 결과 위에 이론 이항분포와 정규분포 곡선을 겹쳐 그리고 ‘닮음 점수’로 비교하면서, 정규근사가 잘 되는 조건을 찾습니다.

수학적 원리

B(n, p): 평균 np, 표준편차 √(np(1−p))
n이 크고 p가 0.5에 가까울수록 N(np, np(1−p))에 가깝다
  • 경험적 기준 np ≥ 5, n(1−p) ≥ 5(목적에 따라 10). 절대적 보장 조건이 아니라 오차 허용 범위에 따른 판단입니다.
  • 연속성 보정: P(X = k) ≈ P(k − 0.5 ≤ Y ≤ k + 0.5), Y는 정규분포.
  • 닮음 점수(교육용, 최고 99): 확률 일치 25% + 막대 촘촘함 25% + 근사 조건 35% + 대칭성 15%.

시뮬레이터에서 확인하기

  • 실험 1: n = 10, p = 0.5에서 ‘반복 실험 1000개 추가’ → 곡선이 맞아 드는 과정
  • p = 0.1로 낮추면 같은 n에서도 점수가 떨어짐 — n만으로 판단할 수 없음
  • 실험 3: n, p만 보고 예측한 뒤 점수를 공개해 비교

행성 탐사 랜덤워크 시뮬레이터

확률변수의 합분산의 덧셈√N

기지에서 출발한 로봇이 매 순간 확률 1/2로 오른쪽·왼쪽 1칸을 이동합니다. 이동 횟수를 4배 늘리면 최종 위치의 분포는 얼마나 더 퍼질까요?

수학적 원리

한 걸음 Y = ±1 (각 1/2): E(Y) = 0, V(Y) = 1
N걸음 후 위치 XN = Y₁ + … + YN → E = 0, V = N, SD = √N
  • 독립인 확률변수의 합은 분산이 더해지므로 퍼짐은 √N에 비례합니다. 이동 4배 → 표준편차 2배.
  • 오른쪽 횟수 R ~ B(N, 1/2)이고 XN = 2R − N → 정규근사 N(0, N).
N = 50 → SD ≈ 7.07 · 4N = 200 → SD ≈ 14.14 · 비율 2.00

시뮬레이터에서 확인하기

  • 로봇 2,000대의 표준편차가 이론값 7.07, 14.14와 맞는지, 비율이 2에 가까운지
  • 로봇 수를 200 → 2,000으로 늘릴 때 히스토그램이 종 모양으로 정리되는 과정
  • 두 분포의 평균이 모두 0 근처에 머무는 것

로봇 랜덤워크 실시간 시각화

경로와 분포정규근사68-95-99.7

로봇 여러 대의 이동 경로를 실시간으로 그리며 도착 위치가 쌓여 분포가 되는 과정을 보고, 회수 반경 안에 남는 비율을 확인합니다.

수학적 원리

XN ≈ N(0, N), σ = √N
반경 L 안에 있을 확률 P(|XN| ≤ L) ≈ 2Φ(L/√N) − 1
  • 68-95-99.7 규칙: L = σ, 2σ, 3σ일 때 약 68%, 95%, 99.7%가 반경 안에 있습니다.
  • 한 로봇의 경로는 예측할 수 없지만, 많은 로봇의 도착 위치는 종 모양으로 안정됩니다. ‘개별의 우연’과 ‘집단의 규칙’을 구분합니다.

시뮬레이터에서 확인하기

  • 시각화 속도를 늦춰 로봇 한 대의 경로를 따라가며 ‘되돌아옴’과 ‘멀어짐’ 관찰
  • 로봇 수를 늘리며 도착 위치 분포가 이론 곡선에 가까워지는 과정
  • 반경을 σ, 2σ로 두었을 때 안에 남는 비율이 68%, 95%에 가까운지

탐사 제한과 회수율 분석기

드무아브르-라플라스회수율역설

탐사 횟수를 늘리면 넓게 탐사하지만 기지 회수 반경 L 안에 남을 확률은 줄어듭니다. 회수율 95%를 보장하는 최대 탐사 횟수를 구합니다.

수학적 원리

B(N, 1/2) → 정규근사(드무아브르-라플라스), σ = √N
N = 10,000 → σ = 100 · 22,500 → 150 · 40,000 → 200
  • L = 200일 때 P(|XN| ≤ 200): 2σ → 95.4%, 1.33σ → 81.8%, 1σ → 68.3%. 탐사 4배 → 회수율 95% → 68%의 역설.
  • 회수율 95% 보장: 1.96√N ≤ L → N ≤ (L/1.96)²
L = 200 → N ≤ 10,412 · L = 300 → N ≤ 23,428 (2σ 어림: 22,500)

시뮬레이터에서 확인하기

  • 10K / 22.5K / 40K 버튼으로 반경 200칸 안의 비율이 95 → 82 → 68%로 떨어지는 것
  • 300칸으로 바꾸면 허용 탐사 횟수가 얼마나 늘어나는지 (반경 1.5배 → 횟수 2.25배)
  • 시뮬레이션 비율과 정규근사 값의 차이가 작은지

탐사 최적화 샌드박스

평가지표 설계제약 조건상충 관계

탐사 범위, 회수 확률, 위험도를 결합한 평가지표 S를 두고, 회수 확률 90% 이상이라는 제약 아래 모둠별로 최적 전략(N, L)을 설계합니다.

수학적 원리

S = 탐사 범위 × 회수 확률 × (1 + 위험도)
탐사 범위 = σ = √N · 회수 확률 = P(|XN| ≤ L) ≈ 2Φ(L/√N) − 1
위험도 = 최대 도달 지점(3σ) / 회수 가능 거리 = 3√N/L
  • 제약: 회수 확률 ≥ 0.9 → 1.645√N ≤ L → N ≤ (L/1.645)² (L = 200 → 14,782).
  • N을 키우면 범위는 늘지만 회수 확률은 줄어드는 상충 관계. S는 교육용 모형 지표이며 실제 탐사의 안전을 보증하지 않습니다.

시뮬레이터에서 확인하기

  • N, L 슬라이더로 제약을 지키면서 S가 가장 큰 조건 찾기, ‘이론적 최적점’과 비교
  • 시행 횟수(로봇 수)를 늘리면 실측 회수율이 이론값에 안정되는 정도
  • 모둠별 전략을 표로 모아 범위·회수율·위험도 비교

완전불일치 실험과 자연상수 e

완전순열포함배제1/e

번호 타일 n개를 무작위로 섞어 하나도 제자리에 없을 확률을 여러 기기의 결과를 합쳐 추정하고, 그 극한에서 e를 발견합니다.

수학적 원리

고정점이 0개인 배열(완전순열) 수 Dn = n! Σk=0n (−1)k/k!
pn = Dn/n! = 1 − 1/1! + 1/2! − … → 1/e ≈ 0.3679
D₄ = 24 − 24 + 12 − 4 + 1 = 9, p₄ = 37.5%
  • 포함배제: k개 자리를 고정하는 경우 C(n, k)(n−k)!을 더하고 빼며 겹침을 조절합니다.
  • ‘i번 타일이 제자리’ 사건들은 독립이 아니므로 (1 − 1/n)n이 아닙니다 (n = 2: 실제 1/2, 독립 가정 1/4).
  • 전체 시행 ÷ 성공 횟수 ≈ e. 유한 n에서는 1/pn의 추정이며, 성공 0회면 정의되지 않습니다.

시뮬레이터에서 확인하기

  • 예측 기록 → 각자 1회·10회·1,000회 섞기 → ‘우리의 데이터’에서 성공 합 ÷ 시행 합
  • 해설 공개 후 n = 4의 24가지 배열, 정확한 pn과 1/e 비교, Wilson 95% 구간
  • n을 늘리는 것(pn → 1/e)과 시행을 늘리는 것(추정 안정)의 차이
