1차시

큰수의 법칙

상대도수오차한계

핵심

  • 시행을 늘리면 상대도수는 확률 p에 가까워집니다.
  • 매번 오차가 줄어드는 것이 아니라, 흩어지는 폭이 줄어듭니다.
  • 흩어짐은 1/√n에 비례합니다. 시행 4배 → 폭 절반.
상대도수의 표준편차 = √(p(1−p)/n)
오차한계(2σ) ≤ E 가 되려면 n ≥ 4p(1−p)/E²

시뮬레이터에서 해 볼 것

  • 동전: 경로 5개가 0.5로 모이는 모습 (로그 스케일)
  • 주사위: n = 60 → 600 → 6000, 히스토그램 폭 비교
  • 뽑기(p = 0.05): 오차한계 0.01은 1,900회, 0.005는 7,600회

몬테카를로 방법

원주율발전기 용량

핵심

  • 무작위 점을 뿌려 비율로 넓이를 잽니다. 원 안에 들어갈 확률은 π/4.
  • 점 N이 4배 늘면 오차는 절반만 줄어듭니다 (1/√N).
  • 같은 방법으로 ‘정상 운영 확률’처럼 계산이 어려운 확률도 추정합니다.
π̂ = 4 × (원 안의 점 수)/N, 오차 ≈ 1.64/√N
발전기: 부스 30개 총전력 T, 평균 45, 표준편차 3.67
95% 정상 운영 용량 ≈ 45 + 1.645 × 3.67 ≈ 52

시뮬레이터에서 해 볼 것

  • 원주율: N = 1,000 → 100,000, 추정값과 절대 오차 변화
  • 배치 반복: 같은 N을 50번 반복해 흩어짐 재기 (N 4배 → 1/2)
  • 발전기: 용량별 확률 표에서 95%를 처음 넘는 용량 찾기

3차시

갈톤보드와 이항분포

이항분포기댓값

핵심

  • 공이 오른쪽으로 간 횟수가 도착 칸입니다. 층 k, 확률 p인 이항분포.
  • 중심은 kp, 폭은 √(kp(1−p)). 층이 많아지면 종 모양.
  • 보상 규칙은 칸별 확률 × 상품가의 합(기대 비용)으로 설계합니다.
도착 칸 X ~ B(k, p), E(X) = kp
목표 칸 m 맞추기: p ≈ m/k
기대 운영 비용 = Σ P(칸) × 상품가 < 플레이 비용

시뮬레이터에서 해 볼 것

  • ‘새 미션 받기’ 뒤 p를 조절해 목표 칸 맞추기
  • p = 0.5와 0.3에서 중심과 모양 비교
  • 공 120개와 1,000개에서 최빈 칸이 달라지는지 확인

4차시

표본평균과 신뢰구간

표준오차오차 한계

핵심

  • 표본평균은 모평균 주위에 모이고, 폭(표준오차)은 σ/√n입니다.
  • 표본 4배 → 폭 절반. 비용은 4배.
  • 95% 신뢰구간: 같은 절차를 반복하면 구간의 약 95%가 모평균을 포함합니다.
표준오차 = σ/√n (σ = 20: n = 25 → 4, n = 100 → 2)
95% 신뢰구간 = X̄ ± 1.96 σ/√n
오차 한계 ≤ 2 → n ≥ (1.96 × 20/2)² = 385

시뮬레이터에서 해 볼 것

  • n = 25와 100의 표본평균 히스토그램 폭 비교
  • 신뢰구간 100개 중 빨간(놓친) 구간 세기, 반복하며 누적 비율 보기
  • 목표 오차 한계를 처음 만족하는 표본 크기와 비용

5차시

이항분포의 정규근사

np, n(1−p)닮음 점수

핵심

  • 이항분포는 n이 크고 p가 0.5에 가까울수록 정규분포를 닮습니다.
  • n만 보면 안 되고 np와 n(1−p)를 함께 봅니다 (경험적 기준 5 이상).
  • 닮음 점수는 교육용 지표입니다 (확률 일치·촘촘함·조건·대칭성).
B(n, p) ≈ N(np, np(1−p))
연속성 보정: P(X = k) ≈ P(k − 0.5 ≤ Y ≤ k + 0.5)

시뮬레이터에서 해 볼 것

  • n = 10, p = 0.5에서 ‘반복 실험 1000개 추가’
  • p = 0.1로 낮추면 같은 n에서도 점수가 떨어지는 것
  • 실험 3: n, p만 보고 예측한 뒤 점수 공개

6차시

랜덤워크와 탐사 전략

√N회수율

핵심

  • ±1 걸음을 N번 더하면 평균은 0, 퍼짐(표준편차)은 √N.
  • 이동 4배 → 퍼짐 2배. 넓게 탐사할수록 기지로 돌아올 확률은 줄어듭니다.
  • 회수 반경 L 안에 남을 확률은 정규근사로 계산합니다.
위치 XN ≈ N(0, N), σ = √N
회수율 95% 보장: 1.96√N ≤ L → N ≤ (L/1.96)²
L = 200 → N ≤ 10,412 · L = 300 → N ≤ 23,428

시뮬레이터에서 해 볼 것

  • 질문 1: N = 50과 200의 표준편차 비율 ≈ 2
  • 질문 3: 탐사 10K → 40K에서 반경 200칸 회수율 95% → 68%
  • 종합: 회수 확률 90% 이상을 지키며 지표 S가 가장 큰 N, L 찾기

7차시

e-Tester: 완전불일치와 e

완전순열1/e

핵심

  • 타일 n개를 섞어 하나도 제자리가 아닐 확률은 n이 커지면 1/e ≈ 0.368.
  • ‘각 타일이 제자리’ 사건은 독립이 아니라 (1 − 1/n)n이 아닙니다.
  • 여러 사람의 결과는 비율 평균이 아니라 성공 합 ÷ 시행 합으로 모읍니다.
pn = 1 − 1/1! + 1/2! − 1/3! + … → 1/e
n = 4: 24가지 중 완전순열 9가지, p₄ = 37.5%
전체 시행 ÷ 성공 횟수 ≈ e ≈ 2.718

시뮬레이터에서 해 볼 것

  • 예측 기록 → 1회·10회·1,000회 섞기 → ‘우리의 데이터’에서 합산
  • 해설 공개 후 n = 4의 24가지 배열과 1/e 비교
  • n을 늘리는 것과 시행을 늘리는 것의 차이 토론
